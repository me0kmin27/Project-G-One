# ADR-0001: 제어면 백엔드 기반

- 상태: 승인
- 날짜: 2026-09-09

## 맥락

제어면 구현을 시작하려면 HTTP 프레임워크, 도메인 영속화 경계와 인증 컨텍스트의 최소
기준이 필요하다. 동시에 Authentik, WireGuard, SMB 등 외부 제품의 세부 선택이 핵심
도메인 로직에 결합되지 않아야 한다.

## 결정

- Python 3.12, FastAPI와 SQLAlchemy 2를 API 기반으로 사용한다.
- 모든 업무 조회는 인증 토큰의 `tenant_id`를 서버에서 적용한다. 요청 본문이나 URL로
  tenant를 선택하게 하지 않는다.
- 장치와 원격 지원 동의 수명 주기를 첫 수직 슬라이스로 구현한다.
- 감사 이벤트는 업무 변경과 같은 데이터베이스 트랜잭션에서 추가한다.
- 초기 로컬 영속화는 SQLite를 허용하되 운영 DB는 PostgreSQL과 명시적 마이그레이션으로
  전환한다.
- 현재 HS256 검증기는 로컬 기반을 세우기 위한 임시 경계다. 운영 인증은 Authentik의
  OIDC discovery/JWKS, 키 회전과 표준 클레임 검증을 지원하는 어댑터로 교체한다.

## 결과

서버, 데이터 모델과 테스트를 즉시 실행할 수 있고 tenant 누락이나 교차 조직 객체 조회를
기본적으로 차단한다. 반면 현재 스키마 자동 생성, SQLite, 공유 대칭키 JWT는 운영 준비가
완료된 구성이 아니다. 다음 변경은 Alembic/PostgreSQL, OIDC 인증 어댑터, 상관관계 ID와
append-only 감사 저장소를 우선한다.
